The Python Cortex · Increment 4 · Slice 1

SHADOW scaffold — observe & log, zero behavior change

Status: approved (SHADOW slice) Design: 2026-06-27 Behavior delta: none (byte-identical) Curation & flip: deferred

The cortex is a deterministic support layer that makes the live voice model — Gemini Live — more effective despite its limits (weak working memory, imprecise state tracking). Gemini stays the brain / driver; the cortex is the deterministic executive prosthetic that does the precise bookkeeping; TypeScript stays the resilient I/O shell and the fail-closed floor. This slice ships the SHADOW scaffold only: the seam, the cortex.decide op, the decision-trace contract, and fire-and-forget observation wiring. The cortex observes and logs what it would decide; TypeScript still injects exactly today's brief. v1 logic is an identity baseline — the point is the seam + contract + observability, not the intelligence. Every judgment-laden rule is deferred to a bead.

1 The mental model — an OODA control loop, not a pipeline

The cortex is the deterministic half of the "decide" node in a loop that closes through the world. In SHADOW it is wired only to the context-curation arc, and its output is observed — never applied.

TypeScript (I/O shell · executor · floor) Cortex (deterministic, Python) Gemini Live (the brain) wired this slice deferred / observe-only

2 SHADOW data flow for context — observed, never applied

Two paths run in parallel from the same world snapshot. The live path (TS → synthesizer → brief → Gemini) is untouched. The shadow path (cortex) is fire-and-forget and ends in a logged trace — its output never reaches the injected brief.

live path (applied — today's exact brief) shadow path (observe-only — logged, not applied) fail-closed floor

3 Locked design decisions

From the 2026-06-27 brainstorm. These are settled for the increment; only the deferred items below remain open.

AxisDecision
Gate posture A — "cortex proposes, the gate disposes." The cortex never enforces and never sits on the synchronous, fail-closed enforcement path. (Not exercised this slice — read/feed only.)
Role Deterministic support layer. Gemini reasons; the cortex does the precise, reliable bookkeeping — the executive prosthetic.
Streaming core Pure-reactive — a function of the current snapshot. No internal state baked in.
Decision memory Externalized. Hysteresis / oscillation-damping is an externalized callable owned by the memory/context module, not baked into the core.
Feed model Pull-per-event over the existing seam. The cortex is a stateless consulted transform; risk stays in the resilient TS backend. No second transport.
Curator ↔ budgeter The cortex owns the char-budget; the synthesizer renders. The cortex is the single logic authority; output is an ordered list. The synthesizer becomes an in-process renderer.
Observability Over-document via a structured decision-trace. Every call emits a versioned, structured trace — the substrate for the future shadow trust-gate.

4 Parity invariants (I-P1 … I-P5)

The guarantees that make "zero behavior change" true. Enforced by tests (Python test_cortex.py + dispatch; TS test_cortex_client.ts + test_cortex_shadow_parity.ts; plus the existing wire-version parity test).

I-P1

The brief is identical, cortex or not. synthesizeAsync output and the injected brief are byte-identical whether the cortex is present, absent, slow, or erroring — synthesizeAsync is untouched.

I-P2

Never blocks, never throws. observeCortexShadow is non-blocking (the caller never awaits) and never throws — an unhandled rejection must never reach the live loop.

I-P3

Any miss is a no-op. Cortex unavailable / timeout / error / off-schema ⇒ zero effect on injection (logged-and-ignored, or an "unavailable" trace).

I-P4

Pure & deterministic. cortex.decide yields an identical decision + trace for identical inputs (modulo ts).

I-P5

The daemon survives bad input. A malformed cortex.decide request returns ok:false and the daemon keeps serving — synthesize / approval.parse still work.

5 The decision-trace contract

Every cortex.decide call emits a structured, versioned trace (the over-document principle). In SHADOW, TypeScript logs this and applies nothing. Shape pulled directly from python/synthesizer/cortex.py.

Response (success) — wire v1

{
  "id": "r1", "v": 1, "ok": true,
  "decision": {
    "keep":   ["project", "pane", "breadcrumbs", "board", "frame"],  // v1 IDENTITY: all present tiers, input order
    "drop":   [],
    "rerank": []
  },
  "trace": {
    "cortexVersion": "0.1.0",
    "strategy":      "baseline-identity",
    "ruleFired":     "baseline-identity",
    "inputs": {
      "activePaneId": "p1",
      "sessionId":    null,
      "trigger":      "brief-inject",            // session-start | pane-switch | catch-up | brief-inject
      "tierKeys":     ["project", "pane", "frame"],
      "tierChars":    { "project": 128, "pane": 64, "frame": 32 }  // size probe (future budget input)
    },
    "output": { "orderedKeep": ["project", "pane", "frame"], "dropped": [] },
    "ts": 1234567890                          // = the `now` passed in (epoch-ms)
  }
}

Failure (daemon survives — TS treats as unavailable)

{ "id": "r1", "v": 1, "ok": false,
  "error": { "code": "CORTEX_FAILED", "message": "…" } }

The TS facade (createPythonCortexClient(core)) validates this with CortexDecideResponseSchema and never rejects: any miss — unavailable daemon, error response, schema reject, even a rejected request — resolves to { ok: false }. The observer logs only on ok:true.

7 How it works, in one breath

When a brief is about to be injected, TypeScript snapshots the world into tiers and — in parallel, fire-and-forget — hands those same tiers to the Python cortex, which deterministically decides what it would keep, drop, or re-rank (today: an identity baseline that keeps everything) and emits a structured decision-trace; TypeScript logs that trace and ignores it, then runs the unchanged synthesizer to build and inject exactly today's brief into Gemini Live. If the cortex is absent, slow, or wrong, nothing happens — the live path never noticed it was there. We're building the nervous system before we let it move a muscle.
